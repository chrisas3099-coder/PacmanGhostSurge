Two questions to answer at the bottom of CODE_MAP.md:

1. What is the difference between monsta_list and all_sprites_list? What happens if a sprite is in one but not the other?

monsta_list is used to keep track of the ghosts for ghost collision detection.

all_sprites_list holds the game sprites that are drawn on the screen. If a sprite is not in monsta_list, Pacman will not detect it as a ghost. If a sprite is not in all_sprites_list, it may not be handled with the main group of sprites for drawing.


2. What frame rate is the game set to, and what does the game loop do every frame, in order?

The game is set to 10 frames per second with clock.tick(10).

Each frame, the game handles events and keyboard input, updates Pacman, updates the ghosts, checks collisions and score, draws the game objects and text, checks for win or Game Over conditions, updates the display, and then limits the loop to 10 FPS.
